# Akash Kushwaha — Developer Portfolio

A responsive, modern dark-themed personal portfolio for a Python Developer.

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Create a repository named `akashkushwaha921.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch** and select `main` / root.
4. Your site will be published at `https://akashkushwaha921.github.io`.

## Customize
- Update the bio and project descriptions in `index.html`.
- Update colors and layout in `style.css` using the CSS variables at the top.
- Replace the LinkedIn URL if your profile URL changes.
- Add a real email address only if you want it publicly displayed.

Built with HTML, CSS, and JavaScript.
