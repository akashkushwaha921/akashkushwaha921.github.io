# Akash Kushwaha — Portfolio

A responsive dark-themed personal developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a repository named `akashkushwaha921.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Visit `https://akashkushwaha921.github.io` after deployment finishes.

## Personalise
Update the project descriptions/links and add your preferred email address or phone number if you want those displayed. The current portfolio links directly to your GitHub and LinkedIn profiles.
